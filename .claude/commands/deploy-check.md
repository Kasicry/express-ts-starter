# deploy-check

배포 전 필수 체크리스트를 자동으로 검사합니다.

## 체크 항목

- [ ] TypeScript 컴파일 확인
- [ ] 환경변수 설정 확인 (.env 파일 존재)
- [ ] 데이터베이스 마이그레이션 상태 확인
- [ ] 불필요한 console.log 제거 확인
- [ ] Git 커밋 상태 확인 (변경사항 없음)
- [ ] 테스트 통과 확인
- [ ] 보안 헤더 설정 확인
- [ ] 에러 처리 미들웨어 활성화 확인

## 사용 방법

```
/deploy-check
```

## 실행 결과

각 항목별로 통과/실패 여부를 보여주며, 모든 항목이 통과해야 배포가 가능합니다.
